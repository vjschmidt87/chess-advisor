Pieces

K ♔ King
Q ♕ Queen
R ♖ Rook
B ♗ Bishop
N ♘ Knight
(none) ♙ Pawn

Squares

Each square is named by its file (column, a–h) and rank (row, 1–8).

e4 = column e, row 4

Moves

Piece letter + destination square. Pawns omit the letter.

Ne6 Knight to e6
Qd7 Queen to d7
e4 Pawn to e4

Symbols

x Capture
+ Check
# Checkmate
O-O Kingside castle
O-O-O Queenside castle
=Q Pawn promotes to Queen

Disambiguation

When two identical pieces can move to the same square, the file, rank, or both are added:

Nge2 Knight on file g to e2
R1d2 Rook on rank 1 to d2

Examples

Bxf7+ Bishop captures on f7, check
exd5 e-pawn captures on d5
e8=Q# Pawn to e8, promotes to Queen, checkmate
